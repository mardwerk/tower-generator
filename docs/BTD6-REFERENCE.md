# BTD6 reference

[btd6-atlas](https://github.com/KyleDerZweite/btd6-atlas) is the source for BTD6 tower data. The reference for the proposed Default Profile is capture 56.3, Steam build 24829026, at atlas revision [`a380413`](https://github.com/KyleDerZweite/btd6-atlas/tree/a380413ed809c98654acec7aa37cba40f80bf5c5/data/56.3-build-24829026). Atlas game data and derived tables are licensed CC BY-NC 4.0. Cite the capture, build, revision, and source file when using a value.

The historical generator used this capture for its BTD6-based Profile. Its source mapping and deliberate departures remain available at the [generator history tag](https://github.com/mardwerk/tower-generator/tree/generator-before-validator-reset-2026-09-29/docs/BTD6-REFERENCE.md). The current repository has no active Default Profile or validator.

[Issue #85](https://github.com/mardwerk/tower-generator/issues/85) tracks the directory Profile and validator work. The exact Dart Monkey normalization and relationship between source records and the Default Profile still need owner review before an importer or validator is built.
