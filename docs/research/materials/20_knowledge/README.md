# Research evidence status

These labels describe the inspection recorded with a finding. They do not establish product acceptance or gameplay results.

### Status labels

Every finding in these summaries carries one label.

- **Confirmed**: checked on the review date against primary source content, or reproduced by running the included code or recomputing from the included data.
  Rows that relied on a documentation source repository instead of the rendered page say so.
- **Metadata only**: the source exists, and its title, authors, year or identifier match a search result.
  The content attributed to it was not read.
- **Unverified**: the source or claim could not be accessed or checked. The row says why.
- **Contradicted**: a checked source, another draft or a rerun disagrees. Both sides are named.
- **Proposal**: design proposal, authoring guidance or opinion. It is classified, not verified.
- **Stale link**: the link points outside the import to a path that no longer exists there.
  The row says where the target existed.
