# Character dossiers

One game-agnostic research dossier per character, at `dossiers/<character>.md`, for example `monkey-d-luffy.md`.
Each dossier records source evidence and, separately labelled, adaptation proposals; game mechanics are still decided in the consuming product, such as the Unit specification in [manga-mayhem#17](https://github.com/mardwerk/manga-mayhem/issues/17).

## Sections

1. **Input boundary.** The character, each source with its URL and retrieval date, and the scope labels.
2. **Findings.** Exact quotes, each with its source and passage ID.
3. **Claims not made.**
4. **Missing sources.** Every source that could not be read, with the reason.
5. **Open questions.**
6. **Adaptation proposals.** Marked as proposals and kept apart from the findings.

A dossier stopped by access or quota limits says so in its first line and is not complete.
