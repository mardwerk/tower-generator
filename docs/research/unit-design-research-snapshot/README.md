# Unit Design Research

This project studies how to design Tower Defense and related RTS units from reference characters when game constraints are initially undefined. A future system might turn a character name into abilities, behavior, statistics, upgrades, and an explanation of character fidelity.

> [!NOTE]
> The work inventories prior material, maps scholarship, and records research practice. No representation, knowledge source, model, adaptation method, evaluation framework, scientific contribution, or experimental case has been selected.

The starting [game and character corpora](docs/CORPORA.md) are deliberately varied. Their inclusion does not imply shared mechanics. Visual assets, audio, executable game implementation, and character unit designs are outside the current phase.
